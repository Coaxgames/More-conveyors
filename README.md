# More-conveyor-Forked-Buffed

A mindustry mod that adds a few new blocks.

New armored variants of vanilla distribution blocks.

New armored variants of vanilla liquid distribution blocks.

5 new faster conveyor types

2 new conduits

3 new faster unloaders

1 new larger storage vault

1 new larger storage container

1 new larger liquid tank

2 new batteries

1 new wall that combines the abilities of the Surge Wall, Plastanium Wall and Phase Wall

Titanium-tier variants of Thorium pumps, conduits, batteries, storage blocks, unloaders, routers, bridge conveyors, and junctions. Thorium variants are researched after their titanium counterparts. Armored titanium/Thorium conveyor tiers and titanium/Thorium conduits use matching-tier junctions and bridges during drag placement; surge/composite armored conveyors use their matching junctions. The built-in Titanium Conveyor also uses the mod's Titanium Junction and Bridge Conveyor when drag-placing.

Each push and pull request runs the GitHub Actions build, which validates the mod content, packages a loadable JAR, and uploads it as a commit-specific workflow artifact.

The Java hook is compiled against Mindustry v157 and v160 in CI. The mod keeps its v157 minimum game version; the downloadable JAR is built against v157.
